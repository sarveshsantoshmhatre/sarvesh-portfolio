# Sarvesh Portfolio

Personal developer portfolio built from scratch with HTML, CSS and JavaScript.

## Features

- Custom responsive design
- Dynamic GitHub profile statistics
- Dynamic public project discovery through the GitHub API
- Project cards with repository links and technology tags
- GitHub Pages deployment through GitHub Actions
- No portfolio template or framework dependency
